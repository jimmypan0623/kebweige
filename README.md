It looks like an MPA, but it uses only a single HTML file to dynamically load the DOM generated by each JavaScript file. 
The frontend is built using vanilla HTML and JavaScript, and the backend is powered by PHP.
In the folder ORIGINALDB, there is a database named tkdata. Please import it into MySQL version 8.0 or above. The database connection utility is located in include/BKND/mysqli_server.php. Simply open this file and configure your updated username and password to start using it
